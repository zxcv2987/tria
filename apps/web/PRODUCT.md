# Product

## Platform

web

## Users

Primary: 개발자(developer). 이슈 목록/상세 화면에서 AI 분석 결과를 검토하고, 관련 파일·함수부터 코드 조사를 시작하며, 필요하면 재분석을 요청하고 분석 결과에 피드백을 남긴다. apps/web의 디자인은 이 사용자의 작업(빠른 스캔, 판정 신뢰, 다음 행동 결정)을 최우선으로 최적화한다.

다른 두 사용자는 존재하지만 화면 설계의 1순위는 아니다:
- 개발 관리자: 분석 대기/실패 현황, 프로젝트별 이슈, 반복 원인, 품질·사용량을 확인.
- 행정·운영 담당자: 원래 쓰던 이슈 도구(Asana 등)에 그대로 이슈를 남기며, Tria 웹 화면을 필수로 사용하지 않는다.

## Product Purpose

Tria는 어떤 도구에서 들어오든 이슈를 접수해 지정된 GitHub 저장소를 코딩 에이전트(Codex)로 분석하고, 개발자에게 코드 원인 후보와 추가 점검 항목을 제공하는 AI 이슈 트리아지 플랫폼이다. 이슈를 자동으로 해결하는 제품이 아니라, 개발자가 이슈를 처음 열었을 때 "어디부터 봐야 하는지"가 이미 준비돼 있는 상태를 만드는 것이 목적이다. 성공은 개발자의 초기 코드 조사 시간이 줄어드는 것으로 판단한다.

## Positioning

이슈 소스 도구(Asana, 사내 폼, 다른 트래커 등)를 특정하지 않고 Tria가 정의한 접수 API 하나만 호출하면 연동되는 구조 — "이슈가 어떻게 들어왔는가"와 "분석을 어떻게 시작하는가"를 분리한다. 분석은 GitHub Actions에서 비동기로 실행되며 GitHub App으로 비공개 저장소를 안전하게 읽는다. AI가 제시한 근거 파일은 실제 저장소 존재 여부로 검증한 뒤에만 판정에 반영한다(허위 확신 방지).

## Operating Context

- 내부 전용 도구. 소속 팀 내부 실무에서만 쓰이며, 외부 고객이나 투자자에게 보여줄 필요는 없다.
- 핵심 화면: 이슈 목록(`/issues`), 이슈 상세(`/issues/[id]`, 분석 결과 카드 포함), 프로젝트 설정(`/settings/projects`), 로그인(`/login`).
- 분석 상태는 QUEUED → RUNNING → SUCCEEDED/FAILED로 전이하며 화면에 상태를 노출한다.
- UI 카피는 한국어.

## Capabilities and Constraints

- 분석 결과 판정은 세 가지: CODE_LIKELY(코드 원인 유력) / CHECK_EXTERNAL(외부 점검 권장) / NEED_MORE_INFO(추가 정보 필요). "확실하다"는 표현은 금지, "후보로 보인다"/"확인이 필요하다" 수준의 표현만 허용(문서 15장 표현 원칙).
- 근거(evidence) 파일은 실제 저장소에 존재하는 경로만 표시. 유효 근거가 0개면 CODE_LIKELY도 CHECK_EXTERNAL로 자동 보정된다.
- 기술 스택: Next.js, Tailwind v4, shadcn/radix-ui 컴포넌트, Supabase(Postgres).
- 현재 브랜드 색상/로고 미확정 — shadcn 기본 그레이스케일 테마 그대로 사용 중(`app/globals.css`).

## Brand Commitments

제품명 "Tria" 외 확정된 로고, 컬러, 서체 등 바인딩된 브랜드 자산 없음. 현재 화면은 shadcn 기본 회색조 테마.

## Evidence on Hand

- 실제 분석 결과 예시(`docs/tria-mvp.md` 7장, `docs/tria-production.md` 10장)는 문서상 예시일 뿐 실사용 스크린샷/실데이터 캡처는 없음.
- 실제 고객 후기, 사례 연구, 언론 자료 없음 — 만들어내지 말 것.

## Product Principles

- 개발자의 코드 조사 시작점을 실제로 좁혀주는가가 모든 화면 판단의 기준이다.
- 판정은 항상 검증된 근거에 기반해야 하며, 근거 없는 확정적 표현은 절대 허용하지 않는다.
- 내부 실무 도구로서 화려함보다 스캔 속도·신뢰도·다음 행동 명확성을 우선한다.
- 이슈 소스(Asana 등)에 대한 가정을 화면에 하드코딩하지 않는다 — 접수 경로는 언제든 바뀔 수 있다.
